# thalvior

> 跨境电商 SaaS ERP / OMS / WMS / TMS / CRM / BI / AI 平台

thalvior 从零构建，目标是形成真正互相连通的跨境电商经营操作系统，而不是一组孤立的后台页面。

## 第一阶段产品范围

- SaaS 多租户、认证、组织与 RBAC
- 工作台与经营数据
- 商品主数据：SPU / SKU / 变体 / 属性 / 素材 / 多语言
- Listing 与渠道内容工作流
- AI 商品工作台：翻译、本地化、标题、卖点、描述、SEO、图片、视频任务
- OMS：订单、审核、风控、拆合单、履约
- WMS：仓库、库位、入库、出库、调拨、盘点、库存流水
- 采购：供应商、采购申请、采购单、收货、质检
- 物流业务模型与履约链路
- 财务：成本、费用、收付款、利润
- CRM 与售后
- BI 数据中心
- 自动化工作流、定时任务、Webhook
- Open API / API Key / 审计日志
- 异常处理、重试、任务记录、操作追踪

## 第二阶段外部集成

第三方平台、支付、物流服务商、广告 API、AI 服务商采用 Connector / Provider 抽象，后续逐一接入，不把核心业务绑定在单一供应商上。

## 核心原则

1. 统一领域模型，避免同一业务对象在不同模块重复造数据。
2. 模块必须形成业务闭环：商品 → Listing → 订单 → 库存 → 采购 → 履约 → 物流 → 财务 → 利润 → BI。
3. AI 能力必须能回写业务对象，而不是独立 Demo。
4. 每个阶段通过 Git commit 固化。
5. 未完成的真实能力不伪装成已完成。
